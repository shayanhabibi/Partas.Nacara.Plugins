Load light.tokens.json and dark.tokens.json (from design/tokens, or written by DesignTokens.write), or paste them.

With the tokens imported, draw the theme's components on a Components page, a docs page composed from them in each scheme on an Example page, and a template of each layout on a Layouts page. Components and templates that already exist are kept.

A layout of your own is a frame on the Layouts page named Layout/<name>: duplicate a template and remove the parts it leaves out.
