To your site: change the variables, then Export from variables and save both files into a folder of your site, such as design/tokens. Read them there with Theme.tokens (DesignTokens.fromDirectory "design/tokens").

From your site: load light.tokens.json and dark.tokens.json (written by DesignTokens.write), or paste them, and Import into variables.

With the tokens imported, draw the theme's components on a Components page, a docs page composed from them in each scheme on an Example page, and a template of each layout on a Layouts page. Components and templates that already exist are kept.

A layout of your own is a frame on the Layouts page named Layout/<name>: duplicate a template and remove the parts it leaves out.

Motion

A hover is a variant whose While hovering interaction changes to another variant of its set with Smart animate. Export motion and save motion.json as design/tokens/motion.json in your site, where Partas.Nacara.Plugins.Motion reads it.
